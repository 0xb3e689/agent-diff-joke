A tiny Python 3.13 program (standard library only, no network) that writes a single one-line joke about reviewing an AI coding agent's diff to `/output/entry.txt`. The joke is short on purpose. It sets up the agent's familiar "one-line fix" that ends up touching dozens of files, then ends on a punchline any reviewer of that diff will recognise. Set `OUTPUT_DIR` to write somewhere other than `/output`.

## Run it

```sh
python3 main.py
```
